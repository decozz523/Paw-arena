# Paw Arena

Paw Arena — адаптивная браузерная игра в стиле коллекционных монстров про собак. Она запускается как обычная статическая страница и автоматически перестраивает интерфейс под компьютер, планшет и смартфон.

## Игровые сцены

- **Карты** — просмотр коллекции собак, их редкости, стихии, способности, характеристик и прокачка за победные очки.
- **Магазин** — покупка боксов и паков за победные очки с разными шансами выпадения редкостей.
- **Бой** — выбор бота-противника, пошаговая схватка до 5 раундов с HP, инициативой, щитами, метками, критами, лечением, комбо стаи и наградой за победу.

## Что добавлено для интереса

- Автосохранение прогресса в браузере.
- Миссии с наградами, достижения и серии побед.
- Закрытые боты, которые открываются по мере побед.
- Способности собак и командные синергии для подбора стаи.

## Структура кода

- `src/data.js` — игровые данные: собаки, редкости, паки, боты, миссии и достижения.
- `src/state.js` — создание профиля, загрузка/сохранение и сброс прогресса.
- `src/game.js` — правила игры: экономика, прокачка, паки, достижения и пошаговый бой.
- `src/scenes.js` — разметка отдельных сцен: карты, магазин, бой и прогресс.
- `src/render.js` и `src/main.js` — сборка интерфейса и обработчики кликов.

## GitHub Pages

Проект готов для GitHub Pages в режиме статического сайта: `index.html` подключает CSS и JavaScript относительными путями (`./src/...`), поэтому игра работает как в корне домена, так и в подпапке репозитория, например `/Paw-arena/`.

## Запуск

```bash
npm start
```

После запуска откройте `http://127.0.0.1:4173`.

## Проверка

```bash
npm run check
```
