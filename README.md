# Paw Arena 2.0

Paw Arena 2.0 — адаптивная браузерная арена про собак в духе пошаговых monster-battler игр. Обновление полностью смещает бой в ручное управление: игрок выбирает тройку, активную собаку, цель и один из четырёх ходов — лапу, хвост, щит или супер.

## Игровые сцены

- **Карты** — коллекция из 16 собак с редкостью, стихией, ролью, лором и уникальным набором способностей.
- **Магазин** — покупка боксов за победные очки с переработанными шансами и pity-счётчиком против плохих серий.
- **Арена** — выбор соперника, сборка тройки и ручной бой до 5 раундов с HP, щитами, метками, ожогами, капканами, провокацией, супер-блоком и выбором цели.

## Что добавлено в 2.0

- 8 новых собак: Пиксель, Тара, Скай, Бруно, Вега, Мира, Кай и Руби.
- У каждой собаки есть 4 разные способности: атака лапой, хвостовой контроль, защитный ход и супер.
- Способности раскрываются в бою после выбора активной собаки, чтобы решение было менее очевидным.
- Можно вручную выбирать цель на стороне врага перед применением хода.
- Боты получили новые составы и тактики: контроль, легендарный финальный состав, арены с нестабильными щитами и усилением супер-ходов.
- Дропы стали серьёзнее: изменены веса редкостей, паки копят pity, а сильные паки ускоряют pity быстрее.

## Структура кода

- `src/data.js` — игровые данные: собаки, способности, редкости, паки, боты, миссии и достижения.
- `src/state.js` — создание профиля, загрузка/сохранение и сброс прогресса.
- `src/game.js` — правила игры: экономика, pity-дропы, прокачка, достижения и пошаговый ручной бой.
- `src/scenes.js` — разметка отдельных сцен: карты, магазин, арена и прогресс.
- `src/render.js` и `src/main.js` — сборка интерфейса и обработчики кликов.

## GitHub Pages

Проект готов для GitHub Pages в режиме статического сайта: `index.html` подключает CSS и JavaScript относительными путями (`./src/...`), поэтому игра работает как в корне домена, так и в подпапке репозитория, например `/Paw-arena/`.

## Запуск

```bash
npm start
```
